Setup Guide

RP2350 - Uses internal pull-down resistors. Buttons wire to 3V3.

  1. Step 1: Download Firmware (.uf2)

    Download the synth workshop UF2 firmware for your board.

    Download for Pico 2 (RP2350)

    Download for Pico (RP2040)

  2. Step 2: Flash Firmware

    Hold BOOTSEL, plug in USB, drag .uf2 onto the mass storage device.

  3. Step 3: Copy Code

    Copy code.py and synth-config.json to the CIRCUITPY drive.

  4. Step 4: Install Libraries

    Copy required .mpy files from the Adafruit bundle to CIRCUITPY/lib/.

  5. Step 5: Copy WAV Files (if needed)

    If using WAV wavetables, also copy the wav/ folder to your CIRCUITPY drive.

Wiring Note for Your Board

Pico 2 (RP2350): Uses internal pull-down resistors. Wire buttons between the GPIO pin and 3V3.

    GP0-GP7 ----[ Button ]---- 3V3
                  (pull-down enabled in software)

Pico (RP2040): Uses internal pull-up resistors. Wire buttons between the GPIO pin and GND.

    GP0-GP7 ----[ Button ]---- GND
                  (pull-up enabled in software)

Wiring Guide

Buttons

Connect momentary push buttons between a GPIO pin and 3V3. Internal pull-down resistors are enabled in software (RP2350), so no external resistors are needed.

Connect momentary push buttons between a GPIO pin and GND. Internal pull-up resistors are enabled in software (RP2040), so no external resistors are needed.

    GP0-GP7 ----[ Button ]---- 3V3
    GP0-GP7 ----[ Button ]---- GND

Potentiometers

Connect 10kΩ pots with outer legs to 3V3 and GND, wiper to GP26/GP27/GP28.

    3V3 ----[ Pot ]---- GP26/27/28 ----[ Pot ]---- GND

LDR

Voltage divider with LDR and 10kΩ resistor. LDR to 3V3, junction to ADC pin, resistor to GND.

MPR121 Capacitive Touch

I2C on GP16 (SDA) / GP17 (SCL). 12 touch channels per board. Address 0x5A default.

Accelerometer (LIS3DH)

I2C on GP16/GP17. Provides X, Y, Z acceleration for tilt and motion control.

OLED Display (SSD1306)

128x64 I2C display on GP16/GP17. Address 0x3C.

Speaker (PWM Audio)

PWM on GP15 through RC low-pass filter (1kΩ + 100nF) to speaker.

Pin Summary

  Buttons: GP0-GP7 (8 max) | Analog: GP26-28 (3 max)
  I2C: GP16/17 (shared)    | Audio: GP15    | LED: GP25

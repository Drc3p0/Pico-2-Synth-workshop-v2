Setup Guide

RP2350 - Uses internal pull-down resistors. Buttons wire to 3V3.

  1. Step 1: Download Firmware (.uf2)

    Download the synth workshop UF2 firmware for your board. This firmware stores your configuration in flash memory and reads settings from a JSON file, so you can update your synth setup without re-flashing.

    Download for Pico 2 (RP2350)

    Download for Pico (RP2040)

  2. Step 2: Flash the Board

    Hold the BOOTSEL button while plugging the board into USB. A drive named RPI-RP2 will appear. Drag the downloaded .uf2 file onto that drive. The board reboots automatically and a new drive named CIRCUITPY will appear.

  3. Step 3: Upload Configuration

    Use the "Download JSON" button in the Generated Code section to save your synth configuration. Copy the synth-config.json file to the root of the CIRCUITPY drive. The firmware reads this file on boot to set up your synth, so you can tweak settings by editing the JSON rather than re-flashing.

  4. Step 4: Install Libraries

    Copy the required CircuitPython libraries to the lib/ folder on the CIRCUITPY drive. You may need:

    • adafruit_mpr121.mpy
    • adafruit_lis3dh.mpy
    • adafruit_ssd1306.mpy
    • adafruit_midi/
    • adafruit_bus_device/

    Get these from the CircuitPython Library Bundle.

  5. Step 5: Copy WAV Files (if needed)

    If using WAV wavetables, also copy the wav/ folder to your CIRCUITPY drive.

Wiring Guide

Buttons

Connect momentary push buttons between a GPIO pin and 3V3. Internal pull-down resistors are enabled in software (RP2350), so no external resistors are needed. When pressed, the pin reads HIGH. Any of GP0–GP7 can be used.

Connect momentary push buttons between a GPIO pin and GND. Internal pull-up resistors are enabled in software (RP2040), so no external resistors are needed. When pressed, the pin reads LOW. Any of GP0–GP7 can be used. 

    GP0–GP7 ----[ Button ]---- 3V3
                  (pull-down, normally open)

    GP0–GP7 ----[ Button ]---- GND
                  (pull-up, normally open)

Potentiometers

Connect 10kΩ potentiometers with the outer legs to 3V3 and GND, and the wiper (center leg) to an ADC input pin. Maximum of 3 pots. 

    3V3 ----[ Pot outer leg ]
                |
          [ Wiper ] ---- GP26 / GP27 / GP28
                |
    GND ----[ Pot outer leg ]

LDR (Light Dependent Resistor)

Create a voltage divider with the LDR and a 10kΩ resistor. Connect one leg of the LDR to 3V3 and the other to the ADC pin. Connect the 10kΩ resistor between the ADC pin and GND. As light increases, resistance drops and the voltage at the ADC pin rises. 

    3V3 ----[ LDR ]----+---- GP26–GP28
                       |
                   [ 10kΩ ]
                       |
                      GND

MPR121 Capacitive Touch

The MPR121 communicates over I2C and provides 12 capacitive touch channels (0–11). Connect conductive pads (copper tape, foil, fruit, etc.) to the electrode pins. The default I2C address is 0x5A. For multiple boards, change the address by connecting the ADDR pin to different voltages (0x5A, 0x5B, 0x5C, 0x5D). 

    MPR121          Pico 2
    ------          ------
    SDA   -------   GP16 (SDA)
    SCL   -------   GP17 (SCL)
    VIN   -------   3V3
    GND   -------   GND

    Electrodes 0–11 --- conductive surfaces

Accelerometer (LIS3DH)

The LIS3DH is a 3-axis accelerometer on the same I2C bus as the MPR121 and OLED. It provides X, Y, and Z acceleration values for tilt and motion control. 

    LIS3DH          Pico 2
    ------          ------
    SDA   -------   GP16 (SDA)
    SCL   -------   GP17 (SCL)
    VIN   -------   3V3
    GND   -------   GND

OLED Display (SSD1306)

A 128×64 SSD1306 OLED display on the shared I2C bus (address 0x3C) shows the current voice name, parameter values, and status information. 

    SSD1306         Pico 2
    -------         ------
    SDA   -------   GP16 (SDA)
    SCL   -------   GP17 (SCL)
    VCC   -------   3V3
    GND   -------   GND

Speaker (PWM Audio)

Audio output uses PWM on GP15. Run the signal through an RC low-pass filter (1kΩ resistor + 100nF capacitor) before connecting to a speaker or headphone jack. 

    GP15 ----[ 1kΩ ]----+---- Speaker + / Headphone tip
                          |
                      [ 100nF ]
                          |
                         GND ---- Speaker − / Headphone sleeve

Pin Summary

  Type            | Pins                   | Max
  ----------------+------------------------+--------
  Buttons         | GP0–GP7                | 8
  Analog (pots)   | GP26, GP27, GP28       | 3
  I2C             | GP16 (SDA), GP17 (SCL) | shared
  Audio PWM       | GP15                   | 1
  LED             | GP25                   | 1

Tips

  • All I2C devices (MPR121, LIS3DH, SSD1306) share the same bus on GP16/GP17.
  • Use short wires for I2C connections to avoid signal degradation.
  • Buttons use internal pull-downs (RP2350) — wire to 3V3, no external resistors needed.
  • Buttons use internal pull-ups (RP2040) — wire to GND, no external resistors needed.
  • Keep analog wires away from the speaker/PWM line to reduce noise.
  • The RC filter on the audio output smooths the PWM into an analog-like signal.
  • For louder output, connect the filtered PWM to a small amplifier module (e.g., PAM8403).
  • Double-check 3V3 vs GND orientation — reversed power can damage I2C boards.
  • GP25 drives the onboard LED and can be used as a status indicator.
